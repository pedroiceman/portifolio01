# portifolio01
Nesta atividade, você atuará como um Desenvolvedor Front-end encarregado de criar o site institucional de uma startup de tecnologia (ex: soluções em IA, desenvolvimento de software ou consultoria). O projeto deve conter pelo menos cinco páginas (ex: Home, Sobre Nós, Serviços, Cases e Contato).

Requisitos Técnicos Obrigatórios:

Separação de responsabilidades: Toda a estilização deve ser feita em um arquivo externo (style.css).
Design Responsivo (Mobile-First): O site deve se adaptar a dispositivos móveis e desktops utilizando Media Queries, além de Flexbox ou CSS Grid para o layout.
Acessibilidade e Semântica: Uso correto de tags HTML5 (como <header>, <main>, <footer>, <nav>) e contraste adequado de cores.
Estilização Moderna: Explorar propriedades do Box Model (margens, paddings, dimensões), tipografia web (fontes externas com unidades relativas como rem), planos de fundo, bordas e, opcionalmente, transições suaves (ex: hover em botões).

Entrega (Submissão):

Em vez de colar o código em um arquivo de texto, você deverá vivenciar o fluxo real de desenvolvimento. Poste na ferramenta Portfólio um documento PDF contendo:

Um link para o repositório público do projeto (ex: GitHub).
Prints (capturas de tela) do site rodando com o detalhamento descritivo de cada tela e suas funções tanto na versão desktop quanto na versão mobile anexados em PDF na SAV.
Pontuação: A atividade vale 1,5 pontos.

Critérios de Avaliação:

Técnica: Correta aplicação do CSS e HTML semântico, além da responsividade funcional.
Organização do Código: Código limpo, indentado e comentado.
Comunicação: Utilização da norma padrão da Língua Portuguesa nos textos do site e nas considerações do PDF, com coerência e coesão.
Atenção às regras: Redução de nota caso algum requisito obrigatório (links que não funcionam, ausência de responsividade) não seja cumprido.
